# `reports/` — Valutazioni e analisi prodotte

## Cosa va qui
I report e le analisi che i modi generano: l'output "ragionato" del framework
(di solito in Markdown), distinto dagli artefatti consegnabili in `output/`.

## Layer
**User Layer.** Mai aggiornato in automatico.

## Buone pratiche
- Naming coerente e datato (es. `2026-06-15-<soggetto>.md`) per ritrovarli.
- Un report per valutazione: facilita confronto e storicizzazione.
- Definisci la struttura del report una volta in `modes/_shared.md` e riusala.

> Nel template questa cartella contiene solo `.gitkeep`: si popola all'uso.
